# Candidate sources for the Flint agentic-coding SFT set (research 2026-10-29, public HF API only)

Searched (sorted by downloads, top 25-50 each): fable, opus, opus-4.8/5, mythos, claude, claude-code(-traces), astra, sonnet, gpt-5.5/gpt-6, gemini-3, distill, reasoning, agentic, swe-agent, trajectories, tool-use, coding-agent, terminal-bench, teich, agent-traces. Raw hit list: build/search.tsv (612 rows). "astra"/"mythos" hits were audio/robotics/unrelated, except the Manusagents-style "Mythos" mixes (junk). Samples were read from the card plus 3-10 rows (datasets-server rows API or the raw file).

Key finding: almost every public "Fable 5" trace set is a re-upload of the same ~60-80 Claude Code sessions (armand0e = Glint-Research = TerraBytes = ronaldcmz; Fable-5-traces family = 30+ identical AGPL mirrors with 29/79 sessions overlapping armand0e; kelexine and saidutta69 are derivatives/aggregators of them). Fable's own thinking is redacted in Claude Code logs, so reasoning is absent in those. The one distinct, large, verified set is DSFFGFG456 (moonshiner).
